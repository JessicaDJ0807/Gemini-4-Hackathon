# Demo wardrobe

Nine fictional garments with stable IDs, categories, colors, style tags, and original SVG illustrations created for this repository. No third-party product photos, brands, prices, or inventory are used. The illustrations may be used and modified with the project.

`wardrobe.mjs` is the canonical catalog (`demo-wardrobe-v1`). B serves illustrations under `/wardrobe/` and returns the catalog from `/api/demo-wardrobe`. These local vector references are for the mock UI; A's future real multimodal service will need reachable image URLs in a supported raster format. They do not establish actual fit, fabric, warmth, or weather resistance.
