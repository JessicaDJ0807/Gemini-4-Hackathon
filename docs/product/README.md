# Product Scope

The MVP sequence is: **Style onboarding → Trip setup → Daily outfits → Visual previews → Shop missing pieces**.

Users can choose style tags or upload photos/videos; Gemini extracts editable preferences. Trips use destination, dates, attractions, weather, and optional inspiration. Outfit recommendations reference a synthetic image-based wardrobe. Preview modes are a rotating/animated 3D avatar, photo-based virtual try-on, and AI-generated destination scene. Shopping uses actual product listings and explicit checkout approval.

Deferred: social account linking, uploads of the user's own closet, iterative restyling, optimized packing list, and a full evaluation dashboard. Record a small set of genuine multimodal failures for judging.
